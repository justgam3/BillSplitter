# BillSplitter Backend - Release Notes
**Release Date:** March 26, 2026
**Version:** 0.1.0 (Initial Backend Implementation)

---

## 🎉 Overview

This release marks the completion of the **BillSplitter backend authentication system**. The backend has been built using **.NET 10** following **Clean Architecture** principles with **CQRS** pattern implementation. This foundation provides a robust, scalable, and maintainable API for user authentication and email verification.

---

## ✨ Features Implemented

### Authentication & Authorization
- **User Registration** with email and password
- **Email Verification** system with 6-digit codes (15-minute expiry)
- **Email Verification Code Resend** with 30-second cooldown protection
- **User Login** with JWT token generation
- **JWT-based Authentication** with 24-hour token expiry
- **Get Current User** endpoint (protected with JWT)

### Security Features
- **Password Hashing** using BCrypt (work factor: 12)
- **JWT Token Generation** with HS256 algorithm
- **Secure Email Verification** codes generated with cryptographic randomness
- **CORS Configuration** for cross-origin requests
- **Authorization Middleware** for protected endpoints

### Email Integration
- **Resend Email Service** integration for sending verification codes
- Professional HTML email templates
- Configurable sender email address

## 🏗️ Architecture

### Clean Architecture Layers

#### **Domain Layer** (`BillSplitter.Domain`)
**Entities:**
- `BaseEntity` - Abstract base with Id, CreatedAt, UpdatedAt
- `User` - User entity with email verification status
- `EmailVerification` - Verification code management

**Business Logic:**
- Factory methods for entity creation
- Domain-driven methods (`VerifyEmail`, `MarkAsUsed`, `CanResend`)
- Encapsulated state management

#### **Application Layer** (`BillSplitter.Application`)
**CQRS Commands:**
- `RegisterUserCommand` - User registration
- `VerifyEmailCommand` - Email verification
- `ResendVerificationCodeCommand` - Resend verification code
- `LoginCommand` - User authentication

**Queries:**
- `GetCurrentUserQuery` - Retrieve current user information

**Interfaces:**
- `IApplicationDbContext` - Database abstraction
- `IEmailService` - Email sending abstraction
- `IJwtTokenGenerator` - Token generation abstraction
- `IPasswordHasher` - Password hashing abstraction
- `IDateTimeProvider` - DateTime abstraction for testability

#### **Infrastructure Layer** (`BillSplitter.Infrastructure`)
**Database:**
- Entity Framework Core 10 with PostgreSQL provider
- Entity configurations with FluentAPI
- Proper indexing on email and verification codes
- Snake_case column naming convention

**Services:**
- `PasswordHasher` - BCrypt implementation
- `JwtTokenGenerator` - JWT token creation
- `DateTimeProvider` - System time provider
- `ResendEmailService` - Email delivery via Resend API

**Migrations:**
- Database schema ready for migration (requires dotnet-ef tools)

#### **API Layer** (`BillSplitter.API`)
**Controllers:**
- `AuthController` with 5 endpoints

**Middleware Configuration:**
- JWT Bearer authentication
- CORS policy (AllowAll for development)
- Global error handling via controller-level try-catch

## 📡 API Endpoints

### 1. **POST** `/api/auth/register`
Register a new user and send verification email.

**Request:**
```json
{
  "email": "user@example.com",
  "password": "SecurePass123!"
}
```

**Response (201 Created):**
```json
{
  "userId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "email": "user@example.com",
  "message": "Registration successful. Please check your email for verification code."
}
```

---

### 2. **POST** `/api/auth/verify-email`
Verify user email with 6-digit code.

**Request:**
```json
{
  "email": "user@example.com",
  "verificationCode": "123456"
}
```

**Response (200 OK):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "userId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "email": "user@example.com",
  "expiresAt": "2026-03-27T10:30:00Z"
}
```

---

### 3. **POST** `/api/auth/resend-verification`
Resend verification code (with 30-second cooldown).

**Request:**
```json
{
  "email": "user@example.com"
}
```

**Response (200 OK):**
```json
{
  "message": "Verification code resent successfully."
}
```

---

### 4. **POST** `/api/auth/login`
Authenticate user and receive JWT token.

**Request:**
```json
{
  "email": "user@example.com",
  "password": "SecurePass123!"
}
```

**Response (200 OK):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "userId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "email": "user@example.com",
  "expiresAt": "2026-03-27T10:30:00Z"
}
```

---

### 5. **GET** `/api/auth/me`
Get current authenticated user (requires JWT token).

**Headers:**
```
Authorization: Bearer {token}
```

**Response (200 OK):**
```json
{
  "userId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "email": "user@example.com",
  "isEmailVerified": true
}
```

## 🗄️ Database Schema

### Tables

#### **users**
| Column | Type | Constraints |
|--------|------|-------------|
| id | UUID | PRIMARY KEY |
| email | VARCHAR(255) | UNIQUE, NOT NULL |
| password_hash | VARCHAR(500) | NOT NULL |
| is_email_verified | BOOLEAN | DEFAULT false |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

**Indexes:**
- `idx_users_email` (UNIQUE)

#### **email_verifications**
| Column | Type | Constraints |
|--------|------|-------------|
| id | UUID | PRIMARY KEY |
| user_id | UUID | FK → users(id) CASCADE |
| verification_code | VARCHAR(6) | NOT NULL |
| expires_at | TIMESTAMP | NOT NULL |
| is_used | BOOLEAN | DEFAULT false |
| last_resent_at | TIMESTAMP | NULL |
| created_at | TIMESTAMP | NOT NULL |
| updated_at | TIMESTAMP | NOT NULL |

**Indexes:**
- `idx_email_verifications_user_id`
- `idx_email_verifications_code`

## 🚀 Getting Started

### Prerequisites
1. **.NET 10 SDK** installed
2. **PostgreSQL** database running
3. **Resend API Key** (for email sending)

### Setup Instructions

1. **Clone and Navigate:**
   ```bash
   cd backend
   ```

2. **Update Configuration:**
   Edit `src/BillSplitter.API/appsettings.json` with your:
   - PostgreSQL connection string
   - JWT secret key (minimum 32 characters)
   - Resend API key

3. **Install EF Core Tools** (if not already installed):
   ```bash
   dotnet tool install --global dotnet-ef
   ```

4. **Create Database Migration** (restart terminal after installing dotnet-ef):
   ```bash
   dotnet ef migrations add InitialCreate \
     --project src/BillSplitter.Infrastructure/BillSplitter.Infrastructure.csproj \
     --startup-project src/BillSplitter.API/BillSplitter.API.csproj \
     --output-dir Persistence/Migrations
   ```

5. **Apply Migration:**
   ```bash
   dotnet ef database update \
     --project src/BillSplitter.Infrastructure/BillSplitter.Infrastructure.csproj \
     --startup-project src/BillSplitter.API/BillSplitter.API.csproj
   ```

6. **Run the API:**
   ```bash
   dotnet run --project src/BillSplitter.API/BillSplitter.API.csproj
   ```

7. **Test the API:**
   - Open browser: `https://localhost:5001/api/auth` (or the port shown in console)
   - Use Postman, Insomnia, or any HTTP client to test endpoints
